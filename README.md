# NearZo - B2B Tyre Marketplace Website

NearZo is a modern B2B Tyre Marketplace website designed to connect tyre dealers, retailers, wholesalers, distributors, and automotive businesses. It is built to build trust, showcase platform capabilities, and attract dealers to download the mobile application.

## Features

- **Home Page:** Dynamic hero presentation with CSS smartphone app mockups, live bid timelines, feature highlights, and localized dealer coverage grids.
- **About Us:** Highlighting our mission, vision, core values, and sourcing metrics.
- **Contact Us:** Interactive lead generation form with active phone/WhatsApp links, and a stylized map pin locator.
- **FAQs:** Accordion-powered interface addressing platform use, quotes, and security.
- **App Download Page:** Direct link to APK, features checklists, mobile UI walkthrough mockups, and QR-code scanning cards.
- **Legal Compliance Pages:** Play Store-compliant Privacy Policy, Terms & Conditions, Refund Policy, and Disclaimer.
- **Fully Responsive:** Mobile-first layout with floating action elements (WhatsApp support chat, sticky app download bars).

## Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Vanilla CSS3 (Custom variables, glassmorphism card overlays, pulse radar dots)
- **Logic:** Vanilla JavaScript (Drawer toggles, scroll headers, accordions, form validators, toast alerts)
- **Icons & Graphics:** Clean, inline SVG elements (no image request latency)
- **Sourcing Engine:** Built-in lightweight local node server script

## How to Run Locally

You can run this project locally without any external packages or build systems using Node.js:

1. Clone this repository.
2. Open your terminal in the project directory.
3. Run the following command:
   ```bash
   node server.js
   ```
4. Open your browser and navigate to `http://127.0.0.1:8000/`.
